# 规则库改动必须经人确认

规则文件的内容变化不会自动生效；一旦内容与上一次人工确认的摘要不一致，规则库进入待确认状态，所有命令都走人工审批，直到人复查并确认。这样即使 agent 能写入文件，也只能把自动放行关闭，不能给自己增加权限。

## Considered Options

- 规则文件改动立即生效，依赖文件权限或路径守卫阻止 agent 修改。
- 允许 agent 修改工作区规则文件并以 git 历史事后审计。
- **人确认后才生效。** 这是唯一不依赖文件系统权限的语义防线。

## Consequences

手工编辑规则后多一次确认；规则 UI 必须明确展示待确认状态。代价换来的是规则自授予不会形成权限提升：未确认内容只会让系统更保守。
